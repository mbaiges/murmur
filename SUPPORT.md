# Support

## Getting help

1. Read [Getting started](docs/user/getting-started.md) (install, first run, updates, troubleshooting).
2. Read [Configuration](docs/user/configuration.md) (settings tabs and per-display behavior).
3. Search or open an issue on [GitHub Issues](https://github.com/mbaiges/murmur/issues).

## Bug reports

Include:

- Murmur version (**Settings → General → App updates**)
- Platform (Windows or macOS)
- What you expected vs what happened
- Whether refresh uses a valid Gemini API key and reachable RSS feeds

Do **not** include your API key or full config file in public issues.
